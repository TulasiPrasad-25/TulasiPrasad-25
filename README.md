## 🚀 Featured Project

### 🛍️ AI Product Review System
> An NLP-powered REST API that performs sentiment analysis, rating prediction, and urgency scoring on e-commerce product reviews.

- 📦 **Dataset:** 200,000+ real product reviews
- 🧠 **Models:** Logistic Regression (TF-IDF) + LSTM (Keras)
- ⚡ **API:** Built with FastAPI — fully documented with Swagger UI
- 🔍 **Features:**
  - Sentiment classification — `positive` / `neutral` / `negative`
  - Star rating prediction (1–5)
  - Urgency/complaint keyword detection
  - EDA endpoints — stats, top words, model comparison
